# ALL NEWCASTLE 2026 — GitHub Pages

Enkel statisk app uten Supabase eller Render.

## Publisering
1. Opprett et offentlig GitHub-repository, for eksempel `all-newcastle-2026`.
2. Last opp `index.html`, `all-newcastle-header.png`, `icon.png`, `manifest.webmanifest` og `.nojekyll` i rotmappen.
3. Under Settings → Pages: Deploy from a branch, `main`, `/ (root)` og Save.
4. Del nettadressen GitHub viser.

## Oppdatere underveis
Åpne `index.html` på GitHub → Edit (blyant) → gjør endringer → Commit changes. Nettsiden oppdateres normalt etter kort tid. Ta gjerne en kopi før større endringer.

## Begrensninger
- Sjekklister og søndagsvalg lagres kun lokalt på den enkelte enheten/nettleseren.
- Ingen felles opptelling, synkronisering eller innlogging.
- Et offentlig GitHub Pages-nettsted gjør deltakerlisten med navn offentlig. Avklar samtykke før publisering.
